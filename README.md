# 🎵 Spotify Song Popularity Prediction

### A Machine Learning Based Spotify Song Popularity Prediction System

## 📌 About The Project

Spotify Song Popularity Prediction is a Machine Learning project that focuses on analyzing Spotify songs and predicting their popularity using different musical features.

This project explores how audio characteristics such as danceability, energy, loudness, acousticness, tempo, and other attributes relate to song popularity.

The main objective is to apply Data Science and Machine Learning techniques to understand music trends and develop a predictive model.

## 🎯 Project Objectives

- Analyze Spotify song datasets.
- Understand the relationship between musical features and popularity.
- Perform data cleaning and preprocessing.
- Conduct Exploratory Data Analysis (EDA).
- Visualize important patterns and trends.
- Apply Machine Learning algorithms.
- Build a model to predict song popularity.
- Evaluate model performance.
